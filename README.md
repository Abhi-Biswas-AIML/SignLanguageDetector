# 🤟 Sign Language Detector

A real-time computer vision application designed to bridge communication gaps by detecting and translating sign language gestures into readable text. This project leverages spatial tracking and machine learning to accurately map hand landmarks and classify gestures on the fly.

## 🚀 Features
* **Real-Time Detection:** Processes live video feeds with minimal latency for instantaneous gesture recognition.
* **Spatial Tracking:** Utilizes advanced hand-landmark mapping to capture complex finger and joint coordinates.
* **Accessibility-Focused:** Designed to interpret sign language dynamically, laying the groundwork for broader accessibility tools.

## 🛠️ Tech Stack
* **Language:** Python
* **Computer Vision:** OpenCV
* **Hand Tracking:** MediaPipe
* **Machine Learning:** Scikit-Learn / Custom ML Classification
